# AI-Based Notification Prioritization Engine

## Problem Statement
Design a smart notification prioritization engine for an automobile CRM system.

The system should:
- Decide notification priority
- Prevent duplicates
- Reduce alert fatigue
- Provide fallback mechanisms
- Include monitoring support

---

## System Overview

CRM Event  
→ API Layer  
→ Feature Engineering  
→ ML Prioritization Engine  
→ Rule Engine  
→ Deduplication  
→ Dispatcher  
→ Monitoring
